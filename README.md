# Fotos del blog · preguntadorenserie.com

Imágenes destacadas optimizadas a WebP (1200 px, calidad 78).

**Este repositorio es público de forma temporal**, solo para poder subir las imágenes
a WordPress vía HTTP. Una vez subidas se pasa a privado.

Contiene únicamente ilustraciones de artículos del blog, que acaban publicadas
en preguntadorenserie.com. Ningún dato personal, ningún texto de consulta.
